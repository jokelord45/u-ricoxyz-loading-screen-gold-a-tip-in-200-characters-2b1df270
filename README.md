One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

## Entry

`main.ts` (Node 22) writes a single loading-screen tip to `/output/entry.txt`:

> Tip: your AI agent just rewrote the file you were reading. Breathe. It was wrong, but confident — exactly like you at 2 a.m. pushing to prod.

## Run

```sh
node main.ts
cat /output/entry.txt
```
